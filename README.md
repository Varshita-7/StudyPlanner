# 📚 StudyPlanner

StudyPlanner is a web-based student productivity and study management application designed to help students organize their academic activities in one place.

It allows students to manage subjects, create and track tasks, plan study sessions, monitor progress, and update their profile.

## ✨ Features

- 🔐 User Registration and Login
- 📚 Subject Management
- ✅ Task Management
- 📝 Add notes to tasks
- ✔️ Mark tasks as completed
- 🗓️ Study Schedule Management
- 📈 Progress Tracking
- 👤 Profile and Settings Management
- 🚪 Secure Logout
- 💾 SQLite Database
- 🔒 Password Hashing
- 📱 Responsive User Interface
